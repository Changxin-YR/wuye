# 部署到生产服务器（www.23331.cloud）

公网入口：`https://www.23331.cloud/wuye/`（子路径反代，nginx 配置见 `deploy/property-23331.nginx.conf`）。

## 服务器布局（沿用既有约定，不要改动）

| 路径 | 用途 |
| --- | --- |
| `/opt/property/releases/<Tag>` | 每次发布一个新目录，旧版本保留 |
| `/opt/property/current` | 软链，指向当前生效的版本 |
| `/etc/property/property.env` | 环境变量（SECRET_KEY / DATABASE_URL / AI_PROVIDER / DASHSCOPE_API_KEY…），**部署不覆盖** |
| `/opt/property/uploads` | 上传目录，**部署不覆盖** |
| `/opt/property/venv` | 运行环境（gunicorn + 依赖） |
| `property.service` | systemd 单元：`gunicorn --workers 2 --threads 2 --bind 127.0.0.1:5003 'app:create_app()'` |

SSH：`ssh -i ~/.ssh/adp_server_ed25519 root@1.14.148.15`（CentOS 7）。

## 部署步骤（本次使用的流程）

```powershell
# 1) 本地打包（排除运行期目录，不打包 .env）
tar -czf $env:TEMP\wuye.tgz -C . --exclude=.venv --exclude=.git --exclude=__pycache__ --exclude=uploads --exclude=artifacts --exclude=.env .

# 2) 上传
scp -i $env:USERPROFILE\.ssh\adp_server_ed25519 $env:TEMP\wuye.tgz root@1.14.148.15:/tmp/wuye.tgz

# 3) 解包到新版本目录并做语法检查（不切换）
ssh -i $env:USERPROFILE\.ssh\adp_server_ed25519 root@1.14.148.15 `
  "set -e; NEW=/opt/property/releases/20260911-v8; rm -rf $NEW; mkdir -p $NEW; tar -xzf /tmp/wuye.tgz -C $NEW; chown -R property:property $NEW; chmod -R u=rwX,g=rX,o= $NEW; for f in app.py agent_planner.py agent_planner_core.py agent_planner_state.py agent_tools.py business_queries.py dify_client.py dify_client_core.py management.py demo_scope.py; do /opt/property/venv/bin/python -m py_compile $NEW/$f || exit 1; done"

# 4) 切换软链并重启（原子替换，失败可立刻回滚）
ssh -i $env:USERPROFILE\.ssh\adp_server_ed25519 root@1.14.148.15 `
  "set -e; ln -sfn /opt/property/releases/20260911-v8 /opt/property/current.tmp; mv -Tf /opt/property/current.tmp /opt/property/current; systemctl restart property; sleep 4; systemctl is-active property; curl -s http://127.0.0.1:5003/health; curl -s http://127.0.0.1:5003/ready"

# 5) 域名自检
curl.exe -s https://www.23331.cloud/wuye/healthz
```

## 回滚

```bash
ssh -i ~/.ssh/adp_server_ed25519 root@1.14.148.15 \
  "ln -sfn /opt/property/releases/<上一个版本> /opt/property/current.tmp && mv -Tf /opt/property/current.tmp /opt/property/current && systemctl restart property"
```

## 排障

- 看日志：`journalctl -u property -n 100 --no-pager`
- 带环境变量单独跑命令（`manage.py` 需要）：
  `set -a; . /etc/property/property.env; set +a; cd /opt/property/current; /opt/property/venv/bin/python manage.py diagnose --ai --infer`
- 服务端 AI Provider 目前是**百炼 qwen-plus**（只有 `DASHSCOPE_API_KEY`）；本地开发用的是 DeepSeek。
  两家模型措辞不同，回答里的内部术语由 `dify_client_core._plain_answer()` 统一兜底清洗。
