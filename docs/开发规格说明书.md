# 美家物业 V2 开发规格说明书

## 1. 技术与边界

系统固定使用 Flask、Jinja2、SQLAlchemy、MySQL 8.4 和阿里云百炼 OpenAI 兼容 API。SQLite 只用于自动测试。所有业务写入由 `property_service.PropertyService` 执行，页面适配层和 Agent 不直接写 ORM 或 SQL。

## 2. 领域模型

V2 以小区、楼栋、单元、房屋为物业主数据；以人员档案和 `house_person` 关系表达业主、家庭成员、租户、联系人及历史；`lease` 保存入住/退租周期。工单、投诉、访客、车辆、车位、设备、巡检和财务（收费项目、账单、收款）均带社区/楼栋范围与版本字段。旧 `sys_user.owner_id` 等字段保留为兼容投影。

## 3. 权限与数据范围

RBAC 数据保存在 `rbac_role`、`role_permission`、`user_role`、`user_scope`。内置岗位包括超级管理员、物业经理、楼栋管理员、客服、前台、财务、工程维修、保安、保洁、普通工作人员和住户。`Policy` 同时检查权限、社区/楼栋范围和住户当前有效关系；过期或结束关系不再授权。

登录会话只读取数据库中的用户状态、角色和 `auth_version`。停用、改密、岗位/范围变更会使旧会话和 Agent 授权失效。浏览器表单、模型文本和 Agent 参数中的身份字段不能改变当前操作者。

## 4. 业务规则

- 报修：业主只能关联自己当前可访问的房屋；公共区域报修必须保留位置和联系人。重复提交可用幂等键安全重放。
- 工单：待派单→已派单→维修中→待验收→已关闭；待派单/已派单可取消，待验收可返修。接单、进度、完工、验收、评价均检查操作者、版本和前置状态。
- 关系：绑定、解除、入住、退租写入历史；仍有有效关系或未完成任务时禁止危险变更。
- 财务：金额以分为整数，账单金额/已付金额受数据库检查约束；批量账单按楼栋范围原子生成并可安全重复；收款和冲销均留痕。
- 高风险：解除关系、退租、停启账号、岗位/权限修改、归档/作废、取消和收款冲销等命令在 Agent 或管理页面先生成待确认操作，确认时重新检查授权、版本和状态。
- 审计：每次业务命令记录操作者、角色、来源、目标、前后快照、trace id、结果和错误；敏感字段不会写入快照。

## 5. 页面与接口

兼容页面 `/houses`、`/users`、`/notices`、`/orders`、`/audit` 保留原 URL，但所有读写均经过 `Policy`、`BusinessService` 或 `PropertyService`。管理模块统一位于 `/manage/<module>`，业务 API 为 `/api/business/<command>`，报表为 `/api/reports/*`。响应包含安全 Header、CSRF 校验和并发冲突处理。

## 6. Agent 与百炼

`/ai/chat` 只把当前用户可见的工单、房屋、公告和身份摘要发送给百炼，最多 20 条工单和 5 条公告。会话映射保存在 `ai_conversation`，权限范围变化会更换上游会话；客户端不能提交上游 conversation id 作为本地会话。百炼使用 `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`，模型默认 `qwen-plus`。请求体传 `stream=true` 时返回 `text/event-stream`，按 `delta` 增量输出，结束事件携带本地会话 ID；未传时保持 JSON 兼容响应。

`/api/agent/tools` 使用短期一次性授权令牌。`context` 获取命令目录，`lookup` 只读查询，普通 `execute` 直接执行，高风险 `propose` 只产生待确认卡片；服务端确认接口再次调用业务 Service。百炼鉴权、超时、HTTP 错误、工具调用异常和模型返回异常均转换为安全错误，不暴露内部地址或密钥。

OpenAPI 导入文件：`config/dify_agent_openapi.json`。Agent 系统约束见 `config/agent_system_prompt.md`。

## 7. 数据库与迁移

`schema.sql` 由当前模型生成，包含 34 张表、外键、唯一约束、检查约束、索引、内置 RBAC 数据和 `property_v2` 迁移标记。新库使用 `python manage.py init-db` 或执行脚本；旧库先备份，再执行 `python manage.py upgrade-db`。迁移不会覆盖原数据，历史维修账号需管理员重新核验。

## 8. 验证基线

```powershell
python -m unittest discover -s tests -v
python manage.py upgrade-db
python manage.py diagnose --ai --infer
```

自动测试覆盖 131 项：领域模型与服务、权限/范围和越权、旧页面、幂等/版本/事务、财务精度、迁移 DDL、Agent 确认闭环、授权指纹/最小披露、百炼 OpenAI 兼容 HTTP/SSE。真实 MySQL 与百炼诊断已在部署环境执行通过。
